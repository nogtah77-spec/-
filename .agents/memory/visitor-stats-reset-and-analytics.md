# معمارية التصفير التلقائي لإحصائيات الزوار ومسار التحليلات الحقيقي

## السياق والدافع
كانت إحصائيات الزوار في لوحة الإدارة (`admin/Analytics.tsx`) وعدادات الزوار (`DataContext.tsx`) تتراكم دون دورة تصفير زمنية محددة، أو تظهر أرقاماً استاتيكية غير متزامنة مع الجلسات اللحظية. طلب المستخدم دورة تصفير دورية واضحة ودقيقة تتطابق مع توقيت العمل الفعلي:
1. تصفير يومي للزوار كل ليلة عند منتصف الليل (الساعة 12:00 ص بتوقيت مكة/القاهرة).
2. تصفير أسبوعي يبدأ صباح كل يوم سبت (بداية الأسبوع العملي).
3. تصفير شهري يبدأ في اليوم الأول من كل شهر ميلادي.
4. حساب الإجمالي الكلي (`allTime`) التراكمي دون أي تصفير.

## القواعد والحلول المعمارية المعتمدة

### 1. مفاتيح التوقيت الزمني الدقيقة (`supabaseService.ts`)
- يتم استخراج المفاتيح وفق توقيت `Asia/Riyadh` كمرجع موحد:
  - **مفتاح اليوم (`todayKey`)**: بصيغة `YYYY-MM-DD`.
  - **مفتاح الأسبوع (`weekKey`)**: يُحسب تلقائياً بالرجوع لآخر يوم سبت (`daysSinceSaturday = (dt.getUTCDay() + 1) % 7`) ليكون السبت هو نقطة بداية الأسبوع.
  - **مفتاح الشهر (`monthKey`)**: بصيغة `YYYY-MM`.
- يتم مقارنة المفاتيح السحابية المحفوظة في مخزن `__visitor_stats_store__`؛ وإذا تغيّر المفتاح، يقوم السيرفر تلقائياً بتصفير العداد المقابل دون الحاجة لمهام مجدولة معقدة (Cron jobs) على الخادم، مما يوفر تكاليف الخوادم ويضمن التصفير التلقائي اللحظي مع أول زيارة في اليوم أو الأسبوع أو الشهر الجديد.

### 2. التوافق مع الكاش المحلي (`alm_visitor_stats_v2`)
- تم ترقية مفتاح الكاش المحلي إلى `alm_visitor_stats_v2` لمنع قراءة الأرقام الوهمية القديمة، وضمان أن يبدأ العداد من الصفر (`0`) بدقة.
- يتم حفظ الحقول الخمسة:
  - `online`: الزوار المتواجدون لحظياً (عبر Supabase Realtime مع استثناء الإدارة).
  - `today`: زوار اليوم.
  - `week`: زوار الأسبوع الحالي (من السبت).
  - `month`: زوار الشهر الحالي.
  - `allTime`: إجمالي الزيارات التاريخية للمنصة.

### 3. قمع التحليلات العقارية الحقيقي (Real Analytics Funnel)
- في صفحة التحليلات (`admin/Analytics.tsx`):
  - تم تحويل مسار التفاعل إلى قمع حقيقي مرتبط بأعداد الزوار الفعليين، الطلبات العقارية، طلبات التشطيب، والتواصل عبر واتساب.
  - تم تقسيم تصنيف العقارات بدقة إلى 3 أبعاد واضحة:
    1. **نوع العرض**: (للبيع / للإيجار / مفروش).
    2. **التصنيف العقاري**: (سكني / تجاري / إداري / طبي).
    3. **الحالة التشغيلية**: (متاح / تم البيع / تم التأجير).
